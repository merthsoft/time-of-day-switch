# Time-of-Day Switches

<!-- merthsoft-download -->
## Download

[Download time-of-day-switch.zip](https://merthsoft.com/RimWorld/time-of-day-switch.zip) — RimWorld 1.7 release.

The archive includes older supported version folders where available. Extract the mod folder into RimWorld's `Mods` directory.
<!-- /merthsoft-download -->

Adds scheduled power switches with optional room-occupancy control. Includes a floor switch and a separate thermostat-style wall attachment. The wall variant requires a supporting wall and does not replace it or control temperature.

[Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=776114412)

See the in-game mod settings for available options. Code is released under the Unlicense.
